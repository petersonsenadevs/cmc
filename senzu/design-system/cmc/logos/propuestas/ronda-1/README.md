# CMC — primera ronda de logotipo

Cuatro propuestas raster generadas a partir del brief del 21 de noviembre de 2026.

- **A — m como flujo:** monograma compacto con estados ámbar y verde.
- **B — hub monolineal:** la `m` reparte dos flujos hacia nodos.
- **C — terminal hub:** símbolo cuadrado independiente con `cmc` y tres salidas.
- **D — mensaje retenido:** la `m` incorpora dos barras de pausa.

Recomendación inicial: **C** para construir el sistema final; **B** si se prioriza un monograma más puro.

Son propuestas de selección, no archivos finales. Tras elegir una se prepararán las versiones oscura, clara, el icono 512×512 y el SVG geométrico.
