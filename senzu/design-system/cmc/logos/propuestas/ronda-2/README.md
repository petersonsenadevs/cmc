# cmc — segunda ronda

Combinación de la propuesta B (monograma monolineal con nodos) y la propuesta D (pausa integrada en la `m`).

## Sistema

- Violeta principal: `#7C5CFF`
- Nodo trabajando: `#F5A524`
- Nodo completado: `#2BB673`
- Texto claro: `#F7F7FA`
- Texto oscuro: `#17171F`
- Sin degradados, sombras ni fondos incorporados.

## Archivos

- `logo-light.svg` / `logo-light.png`: texto oscuro para fondos claros.
- `logo-dark.svg` / `logo-dark.png`: texto claro para fondos oscuros.
- `icon.svg` / `icon.png`: terminal con la `m`-hub y pausa, 512×512.
- `exploracion-chatgpt.png`: boceto raster utilizado únicamente como exploración visual.

Los dos logotipos finales trazan fielmente el boceto de exploración, mantienen las letras `c`, `m` y `c` separadas y llevan todo el texto convertido a contornos SVG: no contienen etiquetas `<text>` ni referencias a fuentes externas.
